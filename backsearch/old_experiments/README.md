# old_experiments

Superseded record-hunting experiments from May-June 2026, kept for reference:
rollout / beam sweeps (`sweep_rollout*.sh`, `bench_rollout.sh`, `*_ab.sh`,
`sweep_phase*.txt`, `curve*`, `longrun*`), simulated annealing over puzzle
configurations (`sa_search.c`), the rollout branch-factor probe (`pathbf.c`),
the old parallel-output filter (`_backsearch_filter.py`) and its launcher
(`run.sh`).  None of this is used by the exhaustive-proof pipeline described in
the top-level README.
