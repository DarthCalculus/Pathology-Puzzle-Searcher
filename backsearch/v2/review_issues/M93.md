## Verifier (CONFIRMED, medium, refuted=False)
Every divergence I checked is real.

fake_server.py:
- heartbeat (:110-126) returns only ok/leases/campaign/me/exits (+revoked). It ignores `holding`/`running` and never returns drop, reclaimed or released. jobs.js:507-560 implements all of those.
- Leasing (:128-175) picks the exit with the most open jobs, then orders by id. jobs.js:275 orders by `j.depth DESC, j.created_at, j.id`, and jobs.js:601-624 adds work stealing.
- The fake has no summary.seed/exit checks (jobs.js:702-705), no level/exit-orbit validation (jobs.js:136), no dup re-issue and no fingerprints (audit returns `"mismatches": []`).
- Unknown token: the fake returns 401 (:113, :130, :185, :303); jobs.js:334 returns 403. Against the real server, volunteer.py:915 `if e.transient or e.status == 401:` is dead code. A 403 or 410 on /reports sends the whole batch to outbox/rejected/, where it is never retried.

fake_worker.py:
- It prints 1-4 random extensions as REMAINING (:170-178). It never prints REMAINING == seed (the real print_remaining at backsearch.c:4326-4329 prints the cursor first, which can be the root) and never more than 4 lines. The real worker can print thousands.
- It never prints the CURSOR/FRONTIER lines the real worker emits on SIGINT (backsearch.c:4645, print_cursor at :4312-4321, up to about 4000 lines).
- It reacts to SIGINT within 0.1 s.
- It always puts the exit on the top row (`cells[exit_cell % w] = "3"`, :90), which is the wrong orbit for exits 6/7/12.

Mitigations, and why this is still medium:
- Server-side drop, steal and release semantics are tested in server/test/v2_gates.test.js:491-555.
- The client ignores unknown line tags.
- The client handles REMAINING == seed explicitly (volunteer.py:784).
So what is untested is the client's reaction: slot SIGKILL on drop (volunteer.py:1202-1214), the 403/410 report paths, and big REMAINING lists. Those paths changed most recently; work stealing is dated 2026-09-24. The lead also reports that test_chaos no longer splits, so there is no real-stack client coverage either.
