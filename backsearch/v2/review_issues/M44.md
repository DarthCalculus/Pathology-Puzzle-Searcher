# M44: compute_exit_syms ignores --place-holes cell masks and --mandatory-holes forced cells, so symmetry folding is unsound when those are asymmetric

verdict CONFIRMED, severity low, category soundness
locations: backsearch.c:348 (compute_exit_syms checks exit, g_walkable_mask, g_fixed_holes_mask only); canonical_state_key; root-direction mask; try_successor --place-holes prune; g_forced_mand_cells

## Summary
The stabilizer used by the canonical root-direction mask and by canonical_state_key checks only the exit, g_walkable_mask and g_fixed_holes_mask. It ignores the --place-holes masks (a prune in try_successor) and g_forced_mand_cells (a solver-side rule). With asymmetric constraints of either kind, states that are not equivalent under them are folded together, and valid levels can be lost.

## Source report F14 (worker-dedup-symmetry)
**compute_exit_syms ignores --place-holes cell masks and --mandatory-holes forced cells, so symmetry folding is unsound when those are asymmetric** at /Users/george/Documents/Claude Projects/project45/backsearch/backsearch.c:348

*summary*: The stabilizer used by the canonical root-direction mask and by canonical_state_key checks only the exit, g_walkable_mask and g_fixed_holes_mask. Two other per-cell constraints, the --place-holes masks (a prune in try_successor) and g_forced_mand_cells (a solver-side rule), are not checked, so states that are not equivalent under those constraints get folded together.

*failure_scenario*: For example: --exit 12 --place-holes 1 6 13 (a hole required at cell 13 by depth 6). All 8 D4 elements pass compute_exit_syms, so the root expands only direction U, and states whose mirror images put the hole at cell 11 are deduped against states that fail the constraint. Levels satisfying the constraint that are reachable only through the pruned image are lost. Campaign #1 uses neither flag.

*evidence*: 348-356: `if (s->cell[exit_pos] != exit_pos) continue; if (apply_sym_mask(s, g_walkable_mask) != g_walkable_mask) continue; if (apply_sym_mask(s, g_fixed_holes_mask) != g_fixed_holes_mask) continue; g_exit_syms[g_n_exit_syms++] = s;`. 2134-2139 `if (g_place[pi].mask == 0) {...} else { ... if (g_place[pi].mask & (1ULL << s->hole_pos[hi])) cnt++; }`. 77 `g_forced_mand_cells` and 5520 `sokoban_set_forced_mandatory(g_forced_mand_cells);`

*suggested_fix*: In compute_exit_syms also require apply_sym_mask(s, g_place[i].mask) == g_place[i].mask for every entry, and apply_sym_mask(s, g_forced_mand_cells) == g_forced_mand_cells. Alternatively disable canonicalisation (g_state_canon=0, mask 0xF) whenever these flags are present.

*expected_gain*: Keeps experimental constrained runs exact; no effect on current campaigns.
