# M67: paused_max_s is filtered out of /state, so the panel always shows the hard-coded '12 h' pause reservation

verdict CONFIRMED, severity low, category bug
locations: volunteer.py:1313 (state() copies a fixed list of campaign keys that omits paused_max_s); volunteer_ui.html `if (c.paused_max_s)`

## Summary
The server sends paused_max_s in every heartbeat's campaign, but state() copies only a fixed list of campaign keys that leaves it out. The UI's `if (c.paused_max_s)` is therefore never true, and the panel always shows the hard-coded '12 h', whatever the campaign sets.
