## Verifier (CONFIRMED, low, refuted=False)
Checked each sub-claim.

(1) Confirmed, and worse than stated. test_split_exact.py:55 calls `p.communicate(timeout=120)`. On timeout Python raises TimeoutExpired, does not kill the child, and the uncaught exception ends the script. The worker is started without --status-every: backsearch.c:505 defaults g_status_every_ms to 0 (off), so it writes nothing to stdout before REMAINING/SUMMARY and never gets SIGPIPE. With `--time 0` it runs to completion, possibly for hours. The same applies to the monolithic reference run at line 70, run('', 0).

(2) Confirmed. Line 52 always sets BS_TRACE_VISITS; the worker writes one line per expanded node (backsearch.c:4638), each up to about 4*PATH_TOK_MAX bytes. Lines 61-63 load each job's file into a set, line 91 unions them, and line 92 also keeps every job's set in jobinfo, so memory is about twice the union. On a campaign-sized subtree of about 10^7 expansions that is GB-scale disk and RAM. Together with (1), an orphan keeps growing the trace file on disk.

(3) Confirmed doc mismatch. The docstring at lines 6-7 says the test asserts visit coverage, but missing visits fail only under SPLITX_STRICT (line 99). The real default assertion is the valid-level set plus best (lines 97-98), which is the right invariant per DESIGN §5.1.

(4) Confirmed but harmless. Line 85 accepts `rem[0] == seed`. The client treats that as no result (volunteer.py:784-785 and 821-826), and the server rejects a child that does not extend the job seed (jobs.js parseTree). The harness instead re-queues the seed. Coverage-wise that is equivalent to leaving the node untouched, so the protocol violation goes unflagged but nothing is hidden. Line 86 also accepts r == '', which the client would reject.

(5) Mostly moot. With seed '', `r.startswith('')` is always true, so the `or seed == ''` is redundant rather than a meaningful skip. Smuggling --seed-path through cfg does work: parse_seed_path resets g_seed_path_n (backsearch.c:1900), so the last --seed-path wins.

Rated low. It is harness robustness, but it matters for the longer campaign-regime subtree tests the next campaign needs.

*fix notes*: Wrap communicate in `try: ... except subprocess.TimeoutExpired: p.kill(); p.communicate(); raise`, or use start_new_session and killpg. Better, make the timeout a CLI flag. Make BS_TRACE_VISITS opt-in (only when SPLITX_STRICT is set) and do not keep per-job visit sets in jobinfo unless strict. Assert `rem[0] != seed` and `r != ''`, and use a token-prefix check with strictly longer paths to mirror volunteer.py:786. Add a --root/--seed option instead of relying on cfg smuggling. Fix the docstring to name the valid-level invariant. Remove tmp in a finally block.
