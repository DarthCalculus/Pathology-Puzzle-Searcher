## Verifier (CONFIRMED, low, refuted=False)
The claim holds.

Port readiness:
- test_client.sh:23-24 fixes SPORT=18931 and UPORT=18766.
- Line 70 (`http_get "$SERVER/api/v2/status" >/dev/null 2>&1 && return 0`) accepts any responder, and nothing checks that SERVER_PID is still alive.
- fake_server.py:480 binds 127.0.0.1:port. A second listener fails with EADDRINUSE, which is visible only in server.log.
- test_chaos.sh:32 has an lsof guard; this script has none.
- A stale server only survives if a previous run died without its EXIT trap (SIGKILL, or a harness killing just the script). Ctrl-C reaches the whole foreground group. The more realistic trigger in this environment is two concurrent runs colliding on the fixed ports.

RNG flakiness:
- fake_worker.py:111 uses `rng = random.Random()`, which is unseeded.
- In test a, roots are layer 8 (fake_server --layer default 8), so children are at depth 9-11. Their duration is uniform(4.5,6)*0.6^k with k=1..3, and each is probed for 2 s within a 6 s budget. With 1-4 children per root, only the first job of each of the 2 workers gets an absorption pass before SIGINT at t=12.
- A quick Monte Carlo of that model gives P(no child absorbed in either job) ≈ 5%. That run fails tree_ok's `ad -ge 1` (line 100), so the 'few percent' claim is right.

Timing:
- Test a's worst case (12 s + ≤25 + ≤20 + ≤60) exceeds done_test's 60 s cap (line 34).
- Test e's `lr ≤ 3` (line 224) and test d's `n -le 5` (line 206) depend on scheduling.
- The fake workers barely use CPU, so the 3-CPU cap matters less than the finder suggests.

It only affects test reliability, not campaigns, so it stays low. Together with the known test-e SIGINT race (fake_worker installs its handler at line 128, after printing its first lines) the suite is flaky.

*fix notes*: Have fake_server bind port 0 and print the chosen port, or at least check `kill -0 $SERVER_PID` after readiness and refuse to start if the port is already answering. Seed fake_worker from an env var (e.g. FAKE_SEED plus pid or seed hash) so failures reproduce. In test a, poll the audit stat absorbed_done instead of sleeping a fixed 12 s, or make at least one child deterministically absorbable. Install fake_worker's signal handlers before the first output line to remove the test-e race.
